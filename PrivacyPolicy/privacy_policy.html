Seção 02

O Que é o Aplicativo

Célula Secreta é um jogo educativo de perguntas e respostas temático sobre biologia celular. O objetivo do jogo é descobrir, por meio de perguntas estratégicas, qual carta (célula ou organela) o adversário escolheu secretamente — inspirado na mecânica clássica do jogo "Cara a Cara".

Funcionalidades principais
  • Modo Solo (Single Player): o usuário joga de forma independente, sem necessidade de conexão de rede.
  • Modo Multiplayer Local: dois jogadores na mesma rede Wi-Fi/LAN podem se conectar para disputar uma partida em tempo real, sem intermediação de servidores externos.
  • Baralho temático: o jogo contém cartas de células (animal, vegetal, bacteriana, fúngica etc.) e de organelas celulares, cada uma com propriedades, funções e ilustrações científicas.
  • Sistema de perguntas: o jogador faz perguntas sobre características das cartas (ex.: "Tem núcleo?", "É procariótica?") para eliminar opções e descobrir a carta do adversário.
  • Código de sala: no modo multiplayer, o anfitrião gera automaticamente um código alfanumérico de 6 caracteres (ex: AB3X7K) que é compartilhado com o outro jogador para ingressar na partida.

Seção 03

Dados Coletados

✅

O Célula Secreta não coleta nenhum dado pessoal. O aplicativo não solicita cadastro, login, nome, e-mail, senha ou qualquer outra informação de identificação pessoal.

A tabela abaixo detalha todos os tipos de informação que o aplicativo processa durante o uso:

📡
Endereço IP local da máquina

Quando o usuário cria uma sala multiplayer, o aplicativo detecta o endereço IPv4 da interface de rede local do próprio dispositivo para anunciá-lo na rede Wi-Fi/LAN. Esse IP é transmitido exclusivamente dentro da rede local durante a duração da sessão e nunca é enviado para servidores externos nem armazenado em disco.

Temporário
🎮
Estado da partida (dados do jogo)

O progresso da partida (cartas selecionadas, perguntas feitas, turno atual) é mantido exclusivamente na memória RAM enquanto o jogo está em execução. Ao encerrar o aplicativo, todos esses dados são descartados automaticamente.

Na memória
📋
Área de transferência (clipboard)

Quando o anfitrião clica em "Copiar Código", o código de sala de 6 caracteres é escrito na área de transferência do sistema operacional para facilitar o compartilhamento. Nenhuma leitura do conteúdo pré-existente do clipboard é realizada.

Escrita apenas

Seção 04

Permissões Necessárias

Para funcionar corretamente, o Célula Secreta pode solicitar as seguintes permissões ao sistema operacional Windows. Cada permissão está descrita com sua finalidade específica:

🌐
Acesso à Rede Local (LAN / Private Networks)

Por que é necessária: O modo multiplayer usa a rede local (Wi-Fi ou cabo) para comunicação direta entre dois dispositivos. O aplicativo abre portas TCP (54321) e UDP (54322) apenas na rede privada para transmitir o estado do jogo entre os jogadores. Nenhum dado trafega pela internet pública.

Multiplayer
📢
Envio de Pacotes Broadcast UDP

Por que é necessária: O anfitrião da partida anuncia periodicamente o código da sala via pacotes UDP de broadcast (transmissão para toda a rede local) para que o outro jogador possa descobrir automaticamente o endereço IP do anfitrião ao digitar o código. Esse mecanismo substitui a necessidade de digitar um endereço IP manualmente.

Multiplayer
🖥
Enumeração de Interfaces de Rede

Por que é necessária: Para identificar corretamente o IP do dispositivo na rede local, o aplicativo lista as interfaces de rede disponíveis (Wi-Fi, Ethernet) e seleciona automaticamente o endereço IPv4 privado mais adequado, descartando adaptadores virtuais (VirtualBox, VMware, Docker) que poderiam causar erros de conexão.

Multiplayer
📋
Acesso à Área de Transferência

Por que é necessária: Permite ao anfitrião copiar o código de sala gerado automaticamente para a área de transferência do Windows, facilitando o compartilhamento. Somente a escrita é realizada — o aplicativo não lê o conteúdo existente na área de transferência.

Opcional
ℹ️

Modo Solo: Ao jogar no modo "Jogar Sozinho", nenhuma das permissões de rede é utilizada. O jogo funciona de forma completamente offline e local nesse modo.

Seção 05

Comunicação em Rede Local

O modo multiplayer do Célula Secreta utiliza uma arquitetura de comunicação direta entre dispositivos (peer-to-peer) exclusivamente na rede local. Veja como funciona:

Fluxo de conexão multiplayer
  • Criação de sala: O anfitrião gera um código aleatório de 6 caracteres (ex: AB3X7K) e começa a transmitir, a cada 2 segundos, um pacote UDP de broadcast contendo esse código junto com seu IP local.
  • Ingresso na sala: O jogador cliente digita o código recebido. O aplicativo escuta pacotes UDP na rede por até 10 segundos para encontrar o broadcast do anfitrião com esse código e obter seu IP.
  • Conexão TCP: Após descobrir o IP do anfitrião, é estabelecida uma conexão TCP direta (porta 54321) entre os dois dispositivos para troca de dados do jogo em tempo real.
  • Dados transmitidos: Apenas o estado do jogo é transmitido (cartas, perguntas, respostas, turno). Nenhuma informação pessoal é enviada.
  • Encerramento: Ao fechar o jogo ou cancelar a partida, todas as conexões e sockets são encerrados imediatamente e os dados são descartados da memória.

Todo o tráfego de rede ocorre exclusivamente dentro da rede local privada (Wi-Fi doméstico, rede escolar, cabo). O aplicativo não realiza conexões com a internet e não possui servidores externos de qualquer natureza.

Seção 06

Armazenamento e Sessão

O Célula Secreta não cria arquivos de configuração, logs persistentes ou bancos de dados no dispositivo do usuário. Os recursos do aplicativo (imagens das cartas, textos das perguntas, estilos visuais) são carregados diretamente do pacote de instalação e mantidos em memória durante a execução.

Resumo do armazenamento
  • Os dados do jogo existem apenas na memória RAM enquanto o aplicativo está aberto.
  • Ao fechar o aplicativo, nenhum dado é salvo no disco rígido ou em nuvem.
  • Não há histórico de partidas, pontuações armazenadas ou preferências salvas.
  • O aplicativo não cria entradas no registro do Windows além das necessárias para instalação normal via Microsoft Store.
